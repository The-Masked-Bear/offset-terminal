FAQ

How is this different from Cursor? +
Cursor is an IDE fork. Offset is a terminal-native agent that forks your git repository into multiple background worktrees, races different AI models (Claude, GPT-4, Gemini) simultaneously, runs your local test suite on all of them, and auto-merges the winner. No GUI. No Electron. Just your terminal.
Does it work with local Ollama models? +
Yes. Offset supports 12+ providers including local offline Ollama nodes, Claude, GPT, Gemini, DeepSeek, Google Antigravity, and OpenRouter. Run completely offline with Llama, Mistral, or Phi.
What is speculative branching? +
Offset forks your git repo into isolated worktrees, sends the same prompt to multiple AI models in parallel, runs your test suite against each result, and merges the branch that passes. You get the fastest correct answer, every time.
Is it really free? +
Offset Lite is free and open-source (AGPL-3.0). Bring your own API keys for any supported provider. Offset Plus ($15/mo) adds multi-model orchestration, priority cloud inference, OAuth integrations, and advanced /flow workflows.
