FAQ

How is this different from Cursor? +
Cursor is an IDE fork. Offset is a terminal-native agent that forks your git repository into multiple background worktrees, races different AI models (like Claude and GPT-4) simultaneously, runs your local test suite on all of them, and auto-merges the winner.
Does it work with local Ollama models? +
Yes. Offset supports 12+ providers including local offline Ollama nodes, Claude, GPT, Gemini, DeepSeek, and Google Antigravity.
