## ⚡ INSTALLATION

Offset requires Python 3.11+ and `pipx`.

### Windows (PowerShell)
```powershell
pipx install git+https://github.com/The-Masked-Bear/offset-terminal.git
```

### Linux & macOS
```bash
pipx install git+https://github.com/The-Masked-Bear/offset-terminal.git
```

### Launch
Just type:
```bash
offset
```
You will be prompted to login to your GitHub or Google account to access **Offset Lite**.
